# GitHub User Activity Viewer

WPF-приложение на C# для просмотра активности пользователей GitHub через API.

## Функциональность

- Поиск пользователей по имени
- Просмотр основной информации о пользователе (аватар, имя, биография)
- Отображение статистики:
  - Количество репозиториев
  - Количество подписчиков и подписок
  - Дата регистрации
- Просмотр списка публичных репозиториев
- Отображение последних коммитов/активности

## Технологии

- **C#** (.NET WPF)
- **WPF (Windows Presentation Foundation)** - графический интерфейс
- **HttpClient** - работа с GitHub REST API
